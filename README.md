# Git Lab

Учебный проект для изучения Git и командной разработки.

## Цели

В рамках проекта демонстрируются:

- работа с локальным и удалённым репозиторием;
- ветвление;
- слияние;
- разрешение конфликтов;
- Pull Request и Code Review;
- stash;
- cherry-pick;
- rebase;
- reset и reflog.

## Информация о проекте

### Инструкция по установке

1. Клонировать репозиторий.
2. Перейти в каталог проекта.
3. Установить pytest.
4. Запустить тесты командой `py -m pytest -q`.
