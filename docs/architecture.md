# Архитектура проекта Git Lab

## Общая информация

Git Lab — учебный Python-проект, предназначенный для демонстрации
основных возможностей Git и организации командной разработки.

Проект содержит несколько независимых функциональных модулей,
созданных в отдельных feature-ветках.

## Структура проекта

```text
git-lab/
├── docs/
│   ├── architecture.md
│   └── api.md
├── src/
│   ├── auth/
│   │   ├── __init__.py
│   │   ├── login.py
│   │   └── register.py
│   └── payment/
├── tests/
│   ├── test_auth.py
│   └── test_payment.py
├── .gitignore
└── README.md
